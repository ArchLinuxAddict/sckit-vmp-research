# Ethics and scope

## Authorization assumptions

The private work used a preserved local sample and private test environments.
There is **no evidence of vendor authorization**, partnership, or endorsement,
and this release does not claim any. Access to an APK or device does not by
itself authorize modification, redistribution, circumvention, or interference
with production services.

## What this project does

- Documents static structures and evidence handling.
- Distinguishes observed runtime behavior from proposed mechanisms.
- Publishes sanitized summaries, selected derived data, and self-contained tests.
- Provides reproducible parser/table code that operates on lawfully obtained
  matching inputs.

## What it does not do

- Distribute APKs, DEX files, native libraries, VMP assets, captures, screenshots,
  logs, activation material, or bypass patches.
- Provide instructions for defeating root/Frida/VPN/integrity/licensing/
  anti-tamper checks.
- Guess, forge, or use activation keys/tokens.
- Manipulate production servers, certificates, or TLS.
- Claim a complete detector map or complete VM semantics.

## Sensitive artifacts

Raw evidence remains private. Public reports redact local paths, device models,
serial/Android IDs, exact IPs/PIDs, project-specific Firebase identifiers, and
full app strings. Full inventories are withheld. The allowlist/audit is in
`publication-audit.md`.

## Reader responsibility

Obtain authorization, protect your devices/data, validate scripts, and comply
with applicable laws/licenses/agreements. If a claim is marked UNRESOLVED, do not
treat it as an implementation fact. See [the disclaimer](../DISCLAIMER.md).
